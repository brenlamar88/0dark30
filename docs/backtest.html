Read this before the numbers. Premiums in this study are synthetic — priced with Black-Scholes from each ETF's trailing realized volatility, because real historical option-chain data is paid vendor data this system doesn't have. Fills are frictionless model mids: no spreads, no slippage, no commissions, no IV-rank gate, no assignment mechanics. Real premiums are usually somewhat richer than modeled (implied > realized on average), but real fills are always worse. Per PLAN.md, a backtest informs rule design and never gates promotion — the live-forward shadow record on the dashboard is the evidence that counts. Generated 2026-08-20T22:06Z.
